# Portfolio — Design Engineer

A plain HTML/CSS/JS rebuild of the Möbius Framer template, adapted for one person.
There's no build step.

## Run locally

```bash
cd "Design Portfolio" && python3 -m http.server 5173
```

Then open http://127.0.0.1:5173. Pages need to be served over http rather than opened as files, because they load scripts and fonts.

## Edit content: the Site Editor

All copy, images, links, placeholders, prices, numbers, projects and notes can be edited in the Site Editor artifact: https://claude.ai/artifact/Bnmj5p7zqa4zkrnuNmUqTa

**Edit on canvas:** the editor's *Edit on canvas* button shows the real pages (published alongside the editor under `site/`) with your saved content. Click text to edit it in place, click an image to upload or pick one you've already uploaded, and use the small toolbar to set links, hide or reset things. Lists, projects and settings stay in the form. After changing the site's own code, republish the editor with the site files under `site/` so the canvas matches.

Edits save automatically. To put them on the site, either:

- ask Claude to "apply my site editor changes and redeploy", or
- click **Export content.js** and replace `assets/js/content.js` (uploaded photos are embedded, shrunk to 1600px).

Applying (what Claude runs): read the editor's saved document (`editor/content`) to a JSON file, download every `asset:<id>` it mentions (Artifact read with the id as `path`), then

```bash
python3 tools/editor/apply.py <editor-content.json> <downloaded-assets-folder>
```

The script resizes each upload for the web (1600px longest side, JPEG quality 76; PNG/WebP/GIF/SVG keep their format). Videos (MP4/MOV/M4V) over 5 MB, and any MOV/M4V, are re-encoded by `tools/editor/compress_video.swift` (macOS AVFoundation, no ffmpeg needed) to a muted H.264 MP4 under 5 MB, 1600px longest side, set up to start playing while it loads. WebM is copied as-is, saves it in `assets/img/` under the field's name (e.g. `home-about-single-person-img1.jpg`), points the content at that file, drops fields reset to default (`null`) and rewrites `assets/js/content.js`. Uploaded images that haven't been applied yet, or files that fail to load, show the gray placeholder rather than a broken image.

How it works: every editable element in the HTML carries a `data-edit` (text), `data-img` (image) or `data-href` (link) key. `assets/js/content-runtime.js` applies the overrides in `assets/js/content.js` on top of the built-in defaults. In text, `{name}`, `{role}`, `{city}` and `{email}` insert your details, and an empty value hides the element. The editor page is generated by `python3 tools/editor/build.py` from `tools/editor/schema.json`, `config.js` and the templates. Rebuild it after adding new sections.

## Defaults: `assets/js/config.js`

| Field | Used for |
|---|---|
| `name` | Nav logo, footer wordmark, the "scramble" sentence, copy throughout |
| `role` | Shown on the About card. The hero shows "Design / Engineer" from `index.html` |
| `location` / `timezone` | The live clock, bottom right (`timezone` is an IANA name such as `Europe/London`) |
| `email`, `socials` | Contact form (it opens the visitor's mail app), "Email Me" buttons, footer links |
| `projects` (max 5) | 3D discs (all 5 in the homepage hero and on the Portfolio canvas), project pages (`project.html?p=<slug>`), featured project on the About page. `disc` = square art printed on the disc (image, animated GIF or short looping MP4/WebM/MOV, played muted at 24 fps; reduced-motion visitors see the first frame), with the disc text over it (`discInk`: `"black"` or `"white"`) |
| `posts` | Feed, homepage Notes, article pages (`article.html?p=<slug>`) |

**Images:** every image is a gray `.ph` placeholder block. For projects and posts, set `image: "assets/img/your-file.jpg"`. For a project's disc, set `disc` to a square image (it's printed edge to edge, with the centre hole cut out); without one the disc uses `image`, then a generated gray cover with the title. Anywhere else, put an `<img>` inside the `<div class="ph">`; it fills the block automatically.

## Pages

- `index.html`: home. Sections: hero 3D disc carousel (pinned; each scroll step brings the next disc forward; drag to browse, click the front disc to open its project, space flips it), scattered-words scroll, ticker reel, services, big numbers, awards, about, clients, process, testimonials, pricing, notes, contact form, FAQ.
- `portfolio.html`: infinite hold-and-drag / scroll canvas. It's a direct port of the template's Infinite Canvas: 12 slots, with your 5 projects repeating as flat discs that tilt toward the pointer on hover.
- `studio.html`: About page for one person: intro with a cursor image trail, scroll-lit statement, snapshot cards, principles, gallery ticker, experience accordion, featured project.
- `feed.html`, `article.html`, `project.html`, `contact.html`, `404.html`.

## Files

- `assets/css/site.css`: all styles. Desktop values are measured from the original at 1440px. Tablet and phone overrides are at the bottom.
- `assets/js/site.js`: nav, clock, custom cursor, Lenis smooth scroll, text reveals, buttons, tickers, accordions, footer.
- `assets/js/home.js`, `work.js`, `studio.js`: page-specific motion.
- `assets/js/intro.js`: the homepage intro. First visit in a tab session: black screen counting 0–100% while the page and discs load, then it lifts to white, "Human / Agentic" slides in and is replaced by "Design / Engineer" in the same masks, then the intro text, nav, clock and © reveal, and the discs fly in last. Later visits skip the loader and start at "Design / Engineer". All timings are at the top of the file; the two first words are editable (`home.hero.pre1` / `pre2`).
- `assets/js/discs.js`: the 3D discs (Three.js 0.170 from jsDelivr, loaded through the import map in `index.html` / `portfolio.html`). Motion and material values are at the top of the file.
- `assets/fonts/`: Inter Display (SIL Open Font License), the same files the template uses.
